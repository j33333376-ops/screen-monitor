# 학생 화면 실시간 모니터

같은 학교 무선망 안에서 학생 화면을 교사 웹 화면으로 중계합니다. 학생은 직접 전송을 시작하고 언제든 중지할 수 있습니다.

**학생 기기: Windows PC + Android 태블릿.** 두 종류의 기기가 같은 수업에 접속하며 확대·이전 캡처·PDF 저장 기능을 함께 사용합니다. Android 앱은 갤럭시탭 S6 Lite / S5e의 Android 13 사용을 기준으로 추가했으며 최소 Android 8.0 이상입니다. 이 배포본은 iPad를 지원하지 않습니다.

## 이번 업데이트 (2026-09-29) — 교사용 설치 파일과 트레이 실행

교사 노트북에서 zip을 풀고 `서버시작.bat`을 찾을 필요가 없어졌습니다. **학생 앱(EXE·APK)은 바뀌지 않습니다.**

- **설치 파일** `screen-monitor-teacher-setup.exe`: 다음 → 설치를 누르면 끝납니다. 관리자 권한 없이 사용자 폴더(`%LOCALAPPDATA%\Programs\ScreenMonitor`)에 설치되며, 시작 메뉴와 바탕 화면에 **학생 화면 모니터** 아이콘이 생깁니다. 지울 때는 Windows 설정 → 앱에서 제거합니다.
  - 설치 첫 화면에서 **모든 사용자용(관리자)**을 고르면 **방화벽 TCP 8080 허용**도 설치 중에 함께 할 수 있습니다. 관리자 권한이 없으면 예전처럼 정보부에 방화벽 허용을 요청하세요.
- **검은 서버 창이 없습니다.** 실행하면 작업 표시줄 오른쪽 끝에 트레이 아이콘(초록 바탕 네모 네 칸)이 생기고 교사 화면이 브라우저에 열립니다. 아이콘을 누르면 교사 화면이 다시 열리고, 이미 실행 중일 때 아이콘을 또 눌러도 교사 화면만 열립니다.
- 트레이 메뉴: **교사 화면 열기 · 저장 폴더 열기 · 설정(비밀번호·저장 폴더) · 서버 기록 보기 · 종료**. 마우스를 올리면 "수업 1개 진행 중"처럼 상태가 보입니다.
- **트레이의 종료는 PDF 저장이 끝날 때까지 기다렸다가 꺼집니다.** 진행 중인 수업이 있으면 먼저 물어본 뒤 수업을 모두 종료하고 학생별 PDF를 저장합니다. 저장에 실패하면 끄지 않고 알려 줍니다(교사 화면에서 PDF 저장 재시도). 새 버전을 덮어 설치하거나 제거할 때도 같은 순서로 먼저 안전하게 끕니다.
- **처음 실행할 때 비밀번호와 저장 폴더를 정합니다.** 기본 저장 폴더는 `문서\학생화면기록`이며, 문서 폴더가 OneDrive로 동기화되는 PC에서는 학생 화면이 클라우드에 올라가지 않도록 `사용자 폴더\학생화면기록`을 씁니다. 설정은 이 PC 사용자 폴더(`%APPDATA%\ScreenMonitorTeacher\config.json`)에 저장됩니다(비밀번호도 이 파일에 들어 있으니 교사 계정을 다른 사람과 같이 쓰지 마세요). 서버 기록은 같은 폴더의 `server.log`입니다.
- **휴대용 zip**도 계속 올립니다. 압축을 풀고 `학생화면모니터.exe`를 실행하면 설치본과 똑같이 동작합니다. 예전 `server/서버시작.bat`도 그대로 들어 있습니다(둘을 동시에 켜면 포트가 겹쳐 뒤에 켠 쪽이 안내와 함께 멈춥니다).
- 서버 수정: 8080 포트를 다른 프로그램이 쓰고 있을 때 안내 문구 없이 오류로 꺼지던 문제를 고쳤습니다.
- 파일 크기: 설치 파일 약 58MB, 휴대용 zip 약 80MB(학생 설치 페이지용 EXE·APK 포함). 서명되지 않은 프로그램이라 SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**으로 진행합니다.

## 이전 업데이트 (2026-09-28) — 학생 앱 1.5.0: 입력 기억·새 버전 알림

**이번에는 학생 앱(Windows EXE·Android APK)도 바뀝니다. 한 번은 학생 기기에 새 앱을 직접 설치해야 합니다.** 이후 버전부터는 앱이 새 버전을 알려 줍니다.

- **Windows 앱이 입력값을 기억합니다.** 서버 주소·학년·반·번호·이름을 이 PC 사용자 폴더(`%APPDATA%\ScreenMonitorStudent\settings.json`)에 저장해, 다음 실행 때 자동으로 채웁니다. 수업 코드는 수업마다 바뀌므로 저장하지 않습니다(Android 앱은 원래 이렇게 동작). 보통은 **수업 코드만 넣고 전송 시작**을 누르면 됩니다.
- **새 버전 알림**: 교사 노트북(서버)에 든 학생 앱이 학생 기기의 앱보다 새로우면, 학생 앱에 **⬆ 새 버전 받기** 버튼이 나타납니다. 누르면 브라우저가 교사 노트북에서 새 파일을 받습니다. 인터넷이 없어도 됩니다.
  - Windows: 받은 파일을 실행하기 전에 트레이 아이콘 우클릭 → **종료**로 기존 앱을 끄세요. 받은 파일 이름이 `학생화면전송 (1).exe`처럼 바뀔 수 있으니 다음부터는 새 파일을 실행합니다. 서명되지 않은 파일이라 SmartScreen 경고가 다시 나올 수 있습니다.
  - Android: 받은 APK를 눌러 설치합니다(처음 한 번은 '이 출처 허용' 필요). 같은 서명이라 기존 앱 위에 업데이트되고 입력해 둔 정보는 남습니다.
  - 자동으로 몰래 설치되지는 않습니다. 학생이 버튼과 설치 확인을 직접 누릅니다.
- **교사 화면**: 이 서버의 앱보다 오래된 학생 앱을 쓰는 학생의 타일에 보라색 **⬆ 앱 업데이트** 표시가 붙습니다. 표시에 마우스를 올리면 버전을 보여 줍니다. 1.4.0 이하 앱은 알림 기능이 없으므로 `/student` 설치 페이지에서 새로 받게 하세요.
- 앱 버전: Windows **1.5.0**(창 제목에 표시), Android **1.5.0 (versionCode 6)**.
- 교사 서버는 앱 파일 옆의 `client/dist/version.json`, `android/dist/version.json`으로 최신 버전을 압니다. 빌드 스크립트가 자동으로 만듭니다(아래 유지보수용 재빌드 참고). 교사용 zip을 새 버전으로 바꾸면 학생 알림도 바로 반영됩니다.
## 이번 업데이트 (2026-09-28) — 저장 중지 → 일시정지, 학생당 PDF 1개

- 교사 화면의 저장 버튼이 **○ 저장 시작 → ⏸ 저장 일시정지 → ● 저장 다시 시작**으로 바뀝니다. 일시정지는 캡처만 멈추고, 모아 둔 캡처는 그대로 보관합니다.
- **PDF는 수업 종료 때 학생마다 1개**로 만듭니다. 중간에 몇 번 멈췄다 다시 시작해도 수업 전체 캡처가 한 PDF에 시간 순서대로 들어갑니다. (이전에는 저장 중지를 누를 때마다 PDF가 따로 생겼습니다.)
- 일시정지 중에는 학생 앱의 기록 표시도 꺼지고, 버튼과 수업 설정 창에 "지금까지 N장 보관 중"이 표시됩니다.
- 한 수업의 기록은 같은 화질로 이어지므로 **저장을 시작한 뒤에는 수업 종료 전까지 화질을 바꿀 수 없습니다.** 캡처 주기는 일시정지 중에 바꿀 수 있습니다.
- ⚠ 기본 화질 캡처는 **수업 종료 전까지 서버 메모리에만** 있습니다. 서버 창을 닫으면 PDF 저장을 시도하지만 Windows가 몇 초 뒤 강제로 끄므로 다 저장하지 못할 수 있습니다. **반드시 교사 화면에서 수업 종료를 누르고 "PDF N개 저장 완료"를 확인한 뒤 서버를 끄세요.** 노트북이 절전·꺼짐 상태가 되지 않게 하세요.
- 수업 전체를 모으므로 저장 메모리 기본 한도를 256MB → 512MB로 올렸습니다. 한도에 닿으면 그때까지의 PDF를 저장하고 수집을 멈춥니다.
- **PDF 각 페이지 오른쪽 아래에 캡처 시각**(예: `2026-09-28 10:42:30`)이 찍힙니다. 교사 노트북 시계 기준이며, 캡처 주기를 바꾸거나 일시정지한 지점도 시각으로 확인할 수 있습니다. 글자 크기는 캡처 해상도에 맞춰 커집니다.
- **지금 바꿀 수 없는 설정을 바꾸려 하면 이유를 알려 줍니다.** 수업 설정 창 맨 위에 🔒 안내가 뜨고 선택은 원래대로 돌아갑니다. 안내는 창을 닫거나 허용된 변경을 할 때까지 남습니다.
  - 화질: 저장을 시작한 뒤(일시정지 포함) 수업 종료 전까지
  - 캡처 주기: 저장 중(일시정지하면 바꿀 수 있음)
  - 수업명: PDF 저장 중이거나 저장 실패 기록이 남아 있을 때
  - 공통: 서버 연결이 끊겼거나, 수업 종료·PDF 저장·일시정지를 처리하는 중일 때
  - 태블릿 등 다른 교사 화면에서 먼저 저장을 시작해 서버가 거절한 경우에도 같은 안내가 뜹니다.- 교사 서버만 바뀝니다. 학생 EXE·APK 업데이트는 필요하지 않습니다.

## 이번 업데이트 (2026-09-28) — 태블릿으로 교사 화면 보기 (선택)

노트북 화면을 프로젝터로 보여 주며 다른 안내를 해야 할 때, 학생 화면 모니터링만 **같은 Wi-Fi의 태블릿 브라우저**로 옮겨 볼 수 있습니다. 쓰지 않으면 지금과 똑같이 노트북에서만 동작합니다.

1. 노트북에서 평소처럼 **수업 시작**을 누릅니다.
2. **수업 설정 → 📱 태블릿 연결 QR 보기**를 누릅니다. **학생에게 보이지 않게 프로젝터 화면을 잠시 가린 뒤** 여세요.
3. 태블릿 카메라로 QR을 찍으면 태블릿 브라우저에 교사 화면이 바로 열립니다. 비밀번호는 필요 없습니다.
4. 노트북의 QR 창은 연결되면 저절로 닫힙니다. 이제 노트북에서는 교사 창을 닫거나 내려 두고 다른 안내 화면을 띄워도 됩니다. **태블릿이 연결되어 있는 동안 수업(저장 포함)은 계속됩니다.**

- 태블릿에서도 학생 화면 확대, 이전 캡처, 메시지, 호출 확인, 저장 시작·일시정지, 수업 종료를 모두 할 수 있습니다. 태블릿을 새로고침해도 같은 수업으로 다시 연결됩니다.
- 도구 모음에 **교사 화면 2대**처럼 연결된 교사 화면 수가 표시됩니다. 연결하지 않은 기기가 늘어나 있으면 누군가 교사 화면을 보고 있다는 뜻이니 확인하세요.
- **QR 안전장치**: QR은 **한 번 찍으면 무효**가 되고, **2분 뒤 만료**되며, 창을 닫거나 새 QR을 만들면 이전 QR도 무효가 됩니다. 프로젝터에 비친 QR을 학생이 나중에 찍어도 들어올 수 없게 하기 위한 것입니다. 만료되면 **새 QR 만들기**를 누르세요.
- **QR이 안 될 때(예비 방법)**: 태블릿 브라우저에서 `http://교사PC의IP:8080`을 열고, 교사 비밀번호를 입력한 뒤 아래 **진행 중인 수업 열기**를 누릅니다. 수업이 하나면 수업 코드는 비워도 되고, 여러 개면 수업 코드를 넣습니다. 수업 설정 창에 이 주소가 적혀 있습니다.
- 비밀번호나 QR을 한 기기에서 10번 잘못 넣으면 그 기기는 5분간 로그인이 잠깁니다. 태블릿이 비밀번호만으로 진행 중인 수업을 볼 수 있게 되었으니 **기본 비밀번호 `teacher1234`는 꼭 바꾸세요.**
- 태블릿도 노트북과 같은 Wi-Fi여야 하고, 노트북 방화벽에서 TCP 8080이 허용되어 있어야 합니다(학생 접속과 같은 조건). 태블릿 알림음은 화면을 한 번 터치한 뒤부터 울립니다(브라우저 정책).
- 이번 변경은 교사 서버(`server/`)에만 적용됩니다(QR 생성용 `qrcode` 패키지 추가). 학생 EXE·APK 업데이트는 필요하지 않습니다.

## 이전 업데이트 (2026-09-26)

- **IP·수업 코드 창에 Wi-Fi 이름과 비밀번호를 함께 표시**합니다. 서버가 교사 PC가 붙어 있는 Wi-Fi 이름(SSID)과 저장된 비밀번호를 `netsh wlan`으로 자동 감지하며 관리자 권한은 필요 없습니다. 감지한 값은 교사 화면(인증된 연결)에만 보내고 학생 쪽에는 보내지 않습니다.

- 이번 변경은 교사 서버(`server/`)에만 적용됩니다. 서버를 다시 실행하고 교사 화면을 새로고침하세요. 학생 EXE·APK 업데이트는 필요하지 않습니다.

## 실행

1. 시작 메뉴나 바탕 화면의 **학생 화면 모니터**를 실행합니다(휴대용은 `학생화면모니터.exe`). 처음이면 비밀번호·저장 폴더를 정합니다. 예전 방식인 `server/서버시작.bat`도 쓸 수 있으며, 번들 `server/node.exe`가 있어 Node.js를 따로 설치할 필요는 없습니다.
2. 자동으로 열린 `http://localhost:8080`에서 교사 비밀번호를 입력합니다. `서버시작.bat`으로 켰다면 기본값은 `teacher1234`이며 시작 파일의 `TEACHER_PASSWORD`에서 바꿉니다.
3. **수업 시작**을 누르고 6자리 수업 코드를 학생들에게 알려줍니다.
4. 학생 브라우저에서 `http://교사PC의IP:8080/student`를 열어 기기에 맞는 앱을 내려받습니다. Windows는 `client/dist/학생화면전송.exe`, Android는 `android/dist/학생화면전송.apk`를 직접 전달해도 됩니다. 교사 화면의 **IP·수업 코드 띄우기**에 표시된 주소, 수업 코드, 학년·반·번호·이름을 입력하고 **전송 시작**을 누릅니다. Android는 시스템 화면 공유 창의 **지금 시작**도 눌러야 합니다. Windows 앱은 창을 닫아도 종료되지 않고 트레이로 숨습니다.
5. 학생이 **선생님 호출**을 누르면 교사 화면 위쪽에 도움 요청 줄이 뜨고 알림음이 울립니다. 이름을 누르면 그 학생 화면이 확대되며 손이 내려갑니다.
6. 교사 화면의 **💬 메시지**로 접속한 학생 전체에게, 확대 화면의 **💬 이 학생에게 메시지**로 한 명에게 짧은 안내 문구를 보냅니다.
7. 학생 타일을 누르면 확대됩니다. **이전**을 누를 때마다 지난 캡처를 한 장씩 확인합니다. **다음**으로 앞으로 이동하거나 **실시간으로**를 눌러 최신 화면으로 돌아옵니다. 좌우 방향키로도 이동하며, 닫기 또는 Esc로 돌아옵니다.
8. 트레이 아이콘의 **종료**를 누르면 수업 종료와 PDF 저장을 마친 뒤 꺼집니다. `서버시작.bat`으로 켰다면 먼저 교사 화면에서 **수업 종료**를 누르고 PDF 저장이 끝난 것을 확인한 뒤 서버 창을 닫습니다.

학교로 옮길 때는 이 폴더 전체를 복사하세요. 네트워크가 바뀌면 교사 노트북 IP도 달라집니다. 학생 프로그램에는 고정 IP 기본값을 넣지 않았습니다. 학년·반·번호는 1~99, 이름은 20자 이내입니다. 같은 학번의 기존 연결은 보호하며 중복 접속한 쪽에 오류를 표시합니다.

학교 방화벽에 TCP 8080 인바운드 허용이 필요할 수 있습니다. 관리자 권한 PowerShell에서 최초 1회 실행하거나 학교 정보부에 요청하세요.

```powershell
New-NetFirewallRule -DisplayName 'screen-monitor-8080' -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
```

포트가 이미 사용 중이면 시작 오류를 안내합니다. 다른 프로그램이나 실행 중인 수업을 강제 종료하지 않습니다.

안드로이드 설치·재빌드·기기 확인 방법은 [안드로이드 안내](android/README.md)에 있습니다. 학생에게 교사 비밀번호를 알려줄 필요는 없습니다. 교사 화면의 **학생 앱 설치** 링크에서도 설치 페이지를 열 수 있습니다.

## 수업명으로 PDF 구분하기 (2026-09-24)

- 교사 화면의 **수업명 · 키워드 (선택)**에 최대 40자로 입력합니다. 예: `분수의 나눗셈`, `비례식 실험`. 비워 두어도 수업을 시작하고 PDF를 저장할 수 있습니다.
- 수업 중에도 **수업 설정**을 열어 입력하고 **수업명 적용**을 누를 수 있습니다. 저장 버튼이나 **수업 종료**를 누를 때는 입력 중인 수업명도 함께 반영합니다. PDF 이름에는 수업 종료 시점의 수업명이 들어갑니다. 새로고침·재접속 시 서버에 적용된 수업명을 복구합니다.
- 파일명 순서: `수업명_학년반_날짜_시각_구간식별자_학번_이름_학생ID.pdf`. 예: `분수의_나눗셈_6학년2반_2026-09-24_093000_a1b2c3d4_60207_김민수_1.pdf`.
- 학년·반은 각 학생의 등록 정보에서 가져오므로 여러 학급이 함께 접속해도 학생별 학급이 들어갑니다. 수업명이 없으면 `6학년2반_2026-09-24_…pdf`처럼 저장됩니다.
- 공백은 파일명에서 밑줄로, 파일명에 사용할 수 없는 기호는 하이픈으로 바꿉니다. 수업명 변경은 이후에 생성하는 PDF에 적용되며 이미 저장된 파일은 바꾸지 않습니다. PDF 생성·실패 재시도 중에는 수업명을 잠시 변경할 수 없습니다.
- PDF 문서 속성의 제목·주제·키워드에도 수업명과 학급을 기록합니다. 화면 캡처의 페이지 수와 화질은 그대로입니다.
- **Gemini Notebook 자동 라벨:** [Google 공식 도움말](https://support.google.com/gemininotebook/answer/16215270?hl=ko)은 소스 5개 이상에서 자동 라벨·분류를 안내하지만, 특정 파일명이나 PDF 속성을 특정 라벨로 연결하는 규칙은 공개하지 않습니다. 이 이름 규칙은 자료 식별을 돕기 위한 것으로 원하는 자동 라벨을 보장하지 않습니다. 같은 수업에는 같은 키워드를 쓰고, 필요하면 Notebook에서 라벨을 직접 추가·수정하세요.
- 이번 변경은 교사 서버에 적용됩니다. 진행 중인 수업과 PDF 저장을 마친 뒤 서버를 다시 실행하고 교사 화면을 새로고침하세요. 학생 EXE·APK 업데이트는 필요하지 않습니다.

## PDF 저장

### 캡처 주기 선택

- 수업 시작 화면의 **캡처 주기**에서 **10초 / 20초 / 30초**를 고릅니다. 기본값은 30초입니다.
- 수업 중에는 **⏸ 저장 일시정지**를 누른 뒤 **수업 설정**에서 캡처 주기를 바꾸고 **● 저장 다시 시작**을 누릅니다. 기록은 같은 PDF에 이어서 쌓입니다. 저장 중에는 바꿀 수 없습니다.
- 주기는 수업마다 따로 기억합니다. 한 서버에서 여러 수업을 열어도 서로 영향을 주지 않습니다.
- 주기를 짧게 하면 PDF 쪽수와 파일 용량, 특히 **AI 분석용 고화질**의 임시 저장 용량이 함께 늘어납니다. 10초 간격이면 1시간에 학생 한 명당 약 360장입니다.
- 시작 파일의 `SAVE_INTERVAL_SEC`은 새 수업이 시작할 때의 기본값입니다. 10·20·30이 아닌 값을 넣으면 그 값도 선택지에 함께 나옵니다.
- **학생 앱은 그대로 써도 됩니다.** 캡처 요청은 서버가 보내므로 주기 변경에 EXE·APK 업데이트가 필요하지 않습니다.

### 저장 화질 선택

- 수업 시작 화면의 **캡처 저장 화질**에서 **기본 / AI 분석용 고화질**을 선택합니다. 기본값은 기존 화질입니다.
- 한 수업의 기록은 학생마다 PDF 1개로 이어지므로, **저장을 한 번 시작한 뒤에는 수업이 끝날 때까지 화질을 바꿀 수 없습니다**(일시정지 중에도 동일). 화질은 수업 시작 전에 고르세요.
- **기본**: 기존처럼 최신 수신 화면을 저장합니다. 일반 화면은 가로 최대 480px, 확대 화면은 Windows 가로 최대 1280px / Android 긴 변 최대 1280px입니다.
- **AI 분석용 고화질**: 저장 시점마다 학생 앱에 별도 캡처를 요청합니다. 기기의 원래 화면에서 **긴 변 최대 2560px, JPEG 품질 85**로 촬영하며 작은 이미지를 확대하지 않습니다. 실시간 타일·확대 전송 화질과 주기는 기존대로 유지합니다.
- 기본 저장 간격은 두 모드 모두 30초입니다. 1시간에 약 120회 수집하며, 같은 이미지가 연속되면 중복 페이지를 생략하고 종료 시 마지막 캡처를 추가 요청합니다.
- **고화질과 절전 복구를 사용하려면 Windows EXE와 Android APK를 이번 버전으로 업데이트해야 합니다.** 구버전 앱은 기본 화질로 저장되며 교사 화면에 인원 수와 업데이트 안내를 표시합니다. 새 앱은 학생 설치 페이지에서 받을 수 있습니다. Android 버전은 1.3.0입니다.
- 고화질 수신이 시간 내 완료되지 않으면 해당 캡처를 생략하고 누락 횟수를 표시합니다. 구버전 앱을 제외하고, 수신 실패를 저화질 사진으로 대체하지 않습니다.
- 고화질 PDF의 파일명에는 `_AI고화질`이 붙습니다. 실제 기기 해상도가 2560px보다 작으면 해당 기기의 원래 해상도로 저장합니다. 파일 용량은 화면 내용과 수집 횟수에 따라 커집니다.

- 시작 파일의 `SAVE_CAPTURES=on`이므로 기본적으로 수업 시작 시 기록 수집이 켜집니다. 원하지 않으면 `off`로 변경하세요.
- 교사 화면의 **○ 저장 시작 → ⏸ 저장 일시정지 → ● 저장 다시 시작**으로 조절합니다. 일시정지는 캡처만 멈추고 모은 이미지는 그대로 보관합니다. 학생 프로그램에도 기록 수집 여부가 표시됩니다(일시정지 중에는 꺼짐).
- 기본 30초마다 새 화면을 수집하고, **수업 종료** 때 학생마다 PDF **1개**를 만듭니다. 중간에 몇 번 일시정지해도 그 전후 캡처가 모두 한 PDF에 시간 순서대로 들어갑니다. 일시정지·접속 종료 직전의 최신 화면도 수집합니다. 고화질은 일시정지·수업 종료 시 마지막 캡처를 요청하며, 학생 연결이 먼저 끊기면 마지막으로 수집한 고화질까지만 남습니다.
- 연속으로 같은 JPEG가 수신되면 중복 페이지를 만들지 않습니다. 확대 모드에서도 최신 고화질 화면을 기록합니다.
- 저장 위치는 **이 폴더의 `captures/날짜/수업코드/`**입니다. `SAVE_DIR`로 변경할 수 있습니다.
- 파일명은 `수업명_학년반_날짜_시각_구간식별자_학번_이름_학생ID.pdf`입니다. 수업명을 비우면 해당 부분은 생략합니다. 파일명의 시각은 그 수업에서 처음 저장을 시작한 시각입니다. 같은 이름의 파일을 덮어쓰지 않습니다.
- PDF 생성 중에는 저장 버튼이 잠깁니다. 완료 또는 실패가 교사 화면에 표시됩니다.
- 저장 실패 시 해당 기록을 보관합니다. 경로·디스크 공간 문제를 해결하고 **PDF 저장 재시도**를 누르세요. 실패한 기록이 남아 있으면 새 수집과 수업 종료를 보류합니다.
- 기본 화질은 원본 기록 이미지를 메모리에 모읍니다. 고화질은 `captures/.pending/구간식별자/`에 JPEG를 임시 저장하여 긴 수업의 모든 이미지를 RAM에 계속 쌓지 않습니다. PDF 완료 후 해당 임시 JPEG를 정리합니다.
- 모든 수업을 합친 미저장 이미지 메모리 한도는 기본 512MB(`MAX_SAVE_MB`)이며, 학생별 한 수업은 최대 3,000장입니다. 기본 화질 35명·10초 주기·50분 수업이 약 230MB입니다. 고화질 이미지는 임시 저장이 끝나면 이 메모리 계산에서 빠집니다. 한도 도달 또는 임시 저장 실패 시에는 수업 중이라도 수집을 멈추고 그때까지의 PDF를 저장합니다. 이후 다시 저장을 시작하면 새 PDF가 됩니다. PDF 생성 작업과 화면 조회 캐시는 별도 메모리를 사용하므로 전체 프로세스 메모리 상한을 의미하지는 않습니다.
- PDF를 쓸 때 `.tmp` 파일을 만들고 완료 시 `.pdf`로 변경합니다. 고화질 임시 JPEG와 최종 PDF가 한동안 함께 존재하므로 저장 드라이브에 여유 공간이 필요합니다.

`server/서버시작.bat`의 설정:

```bat
set TEACHER_PASSWORD=teacher1234
set SAVE_CAPTURES=on
rem 새 수업의 기본 캡처 주기. 교사 화면에서 10/20/30초 중에 고릅니다.
set SAVE_INTERVAL_SEC=30
rem set SAVE_DIR=D:\student-screens
rem set MAX_SAVE_MB=256
```

**주의:** 전원 종료, 작업 관리자 강제 종료, 서버 창 강제 닫기에서는 메모리에 모은 기록을 복구할 수 없습니다. 고화질의 임시 JPEG가 남을 수 있으나 재시작 후 PDF 자동 복구 기능은 없습니다. 반드시 수업 종료와 PDF 완료를 먼저 확인하세요. 화면 기록의 보관·삭제 기준은 학교 운영에 맞춰 정하세요.

## 메시지와 도움 요청

- **메시지 보내기**: 교사 화면 상단의 **💬 메시지**는 접속한 학생 전체에게, 확대 화면의 **💬 이 학생에게 메시지**는 그 학생에게만 보냅니다. 300자까지이며 자주 쓰는 문구 버튼도 있습니다. Enter로도 보냅니다.
- **링크를 보내면 학생이 눌러서 열 수 있습니다.** `https://…`나 `www.…`로 시작하는 주소를 섞어 쓰면 학생 앱에서 그 부분만 파란 밑줄로 표시되고, 누르면 학생 기기의 기본 브라우저가 열립니다. 메시지 입력칸 아래에 찾은 링크 개수를 표시합니다. 주소 뒤에 붙은 문장부호나 `(주소)를`처럼 괄호와 조사가 붙은 경우에도 주소 부분만 링크가 됩니다. 긴 주소가 잘리지 않도록 300자까지 받습니다.
- 보낸 뒤 **몇 명에게 전달되었는지, 구버전 앱이라 받지 못한 학생이 몇 명인지** 대화상자와 상단 안내줄에 표시합니다. 받지 못한 학생을 받은 것처럼 표시하지 않습니다.
- 학생 화면에서는 Windows는 앱 창이 잠시 앞으로 나오며 주황색 상자에 문구가 뜨고, Android는 **선생님 메시지** 알림이 화면 위로 뜬 뒤 앱 화면에도 남습니다.
- **도움 요청(손들기)**: 학생 앱의 **✋ 선생님 호출**을 누르면 교사 화면 위쪽에 도움 요청 줄과 학생 이름 버튼이 생기고, 타일에 주황 테두리와 ✋ 표시가 붙으며 알림음이 한 번 울립니다.
- 교사가 이름 버튼을 누르면 그 학생 화면이 확대되면서 손이 내려갑니다. **모두 확인**으로 한 번에 내리거나, 확대 화면의 **✋ 손 내리기**로도 내립니다. 학생이 직접 **호출 취소**를 눌러도 내려갑니다.
- 손든 상태는 절전·잠금·재접속 뒤에도 유지됩니다. 수업 종료 전까지 놓치지 않습니다.
- **이 두 기능은 학생 앱을 이번 버전으로 업데이트해야 동작합니다.** 구버전 앱은 기존처럼 화면 전송과 PDF 저장만 하며, 교사가 메시지를 보낼 때 인원 수로 안내합니다.
- 배포 파일은 둘 다 새로 만들어 두었습니다. Windows `client/dist/학생화면전송.exe`와 Android `android/dist/학생화면전송.apk`(1.3.0)를 학생 기기에 다시 설치하세요. 캡처 주기 선택만은 구버전 앱에서도 그대로 적용됩니다.

## 이전 캡처 확인

- **저장 시작** 후 PDF 기록용으로 수집한 사진을 확대 화면에서 확인합니다. 기본 간격은 30초이며, 연속으로 같은 사진은 생략됩니다. 첫 캡처가 쌓이기 전에는 이전 버튼이 비활성화됩니다.
- 캡처 순서와 수신 시각을 표시합니다. 지난 사진을 보고 있을 때에도 학생 타일은 실시간으로 갱신되며, 확대 사진은 선택한 캡처를 유지합니다.
- 저장 일시정지·PDF 저장 완료 후에도 해당 수업이 유지되는 동안 확인할 수 있습니다. 교사 화면 새로고침·재접속 후에도 남아 있습니다.
- 조회용 캡처는 서버 메모리에 전체 수업 합계 최대 128MB, 학생별 최대 3,000장까지 보관하며 초과 시 오래된 사진부터 정리합니다. PDF 기록의 보관 한도와는 별개이며, PDF 파일을 변경하지 않습니다.
- 학생을 목록에서 지우거나 수업·서버를 종료하면 조회용 캡처는 사라집니다. 이전 수업의 PDF를 다시 불러오는 기능은 포함하지 않습니다.

## 연결 상태

- Android 1.2.0 이상: 화면 꺼짐·잠금은 전송 대기로 처리합니다. 학생 앱과 수업 정보를 유지하고, 잠금 해제 후 서버에 다시 연결해 전송을 이어갑니다. 화면 꺼짐 대기 동안은 캡처·PDF 수집을 쉬며 교사 타일에 대기 상태를 표시합니다. 네트워크도 잠들면 ‘재연결 대기’로 표시됩니다.
- Windows: 절전 복귀를 감지하면 연결과 캡처 장치를 다시 준비합니다. 잠금·디스플레이 변경에 따른 일시적인 캡처 오류는 2초 간격으로 재시도하며 전송을 종료하지 않습니다. 교사 웹 화면도 절전 후 응답 없는 연결을 감지해 수업을 복구합니다.
- 같은 실행에서의 재접속은 이전 소켓이 남아 있어도 같은 학생으로 복구합니다. 다른 기기의 중복 학번 접속은 계속 차단합니다.
- Android가 화면 공유 권한 자체를 종료하면(특히 Android 15 QPR1 이후 잠금), 앱 알림을 열고 **전송 재개 → 화면 공유 허용**이 필요합니다. 앱 프로세스가 살아 있으면 수업 코드와 학생 정보는 유지됩니다. 운영체제의 권한 종료를 앱이 자동으로 우회하지는 않습니다.
- 명시적인 전송 중지·앱 종료·수업 종료 후에는 자동으로 전송을 시작하지 않습니다. 교사 서버 프로세스가 종료되면 수업은 복구되지 않으며, 교사 연결이 모두 끊긴 채 30분이 지나면 기존 정책에 따라 수업이 종료됩니다. 교사 PC가 절전 중이면 중계도 일시 중단됩니다.
- 업데이트: 진행 중인 수업과 PDF 저장을 마친 뒤 서버를 다시 실행하고, 학생 설치 페이지(`/student`)에서 APK와 EXE를 새로 받으세요. APK는 기존 앱 위에 설치하고, EXE는 트레이 아이콘을 우클릭해 **종료**한 뒤 교체합니다.

실제 기기 확인: Android 각 모델과 Windows 노트북에서 전송 시작 → 학습 앱 이동 → 10~15분 화면 꺼짐/절전 → 잠금 해제 → 같은 학생 타일에서 새 화면 수신을 확인하세요. 복귀 전에 전송 중지 또는 수업 종료한 경우에는 재개되지 않아야 합니다. Windows는 창을 닫아 트레이로 보낸 뒤에도 교사 타일이 계속 갱신되는지 함께 확인하세요. 자동 테스트는 오류·연결 복구를 모사하며 실제 전원 관리 동작은 기기에서 확인해야 합니다.

교사 화면에 서버 연결 여부가 표시되며 일시적인 연결 장애 시 자동으로 복구를 시도합니다. 학생 목록과 확대 화면도 복구합니다. 학생 화면이 오래 도착하지 않으면 수신 지연을 표시합니다. 학생 프로그램은 재접속 뒤에도 화면 전송을 다시 시작하며 오류·수업 종료 뒤 입력란을 사용할 수 있습니다.

이 앱은 신뢰할 수 있는 학교 내부망용 시제품입니다. 교사 공용 비밀번호와 수업 코드 방식이며 개별 학생 계정 인증은 없습니다. 기본 HTTP/WS 통신은 암호화되지 않으므로 인터넷에 포트를 직접 공개하지 마세요. 외부 배포는 인증 및 HTTPS/WSS 구성을 별도로 해야 합니다.

## 윈도우 앱 트레이 아이콘

- 창의 **X**를 눌러도 프로그램이 끝나지 않습니다. 창만 작업 표시줄 오른쪽 끝 트레이로 숨고 화면 전송은 그대로 이어집니다. 처음 숨길 때 그 사실을 알리는 풍선 안내가 한 번 뜹니다.
- 완전히 끝내려면 **트레이 아이콘을 우클릭해 `종료`**를 누릅니다. 학생이 실수로 창을 닫아 수업 중 전송이 끊기는 일을 막기 위한 것이며, 종료 자체는 여전히 학생이 직접 선택합니다.
- 트레이 아이콘을 누르거나 `창 열기`를 고르면 창이 다시 나옵니다. 선생님이 메시지를 보내면 숨어 있던 창도 저절로 올라옵니다.
- 아이콘은 **전송 중이면 초록, 대기 중이면 회색**이고, 마우스를 올리면 현재 상태 문구가 그대로 보입니다. 창을 숨겨도 모니터링 여부를 알 수 있어야 하므로 이 표시는 빼지 마세요.
- 트레이 아이콘을 올리지 못하는 환경에서는 예전처럼 창을 닫으면 종료되며, 창 아래 안내 문구도 그에 맞춰 바뀝니다.
- **전송 중지**는 창에서 그대로 누릅니다. 트레이 메뉴에는 넣지 않았습니다.

## 배포 파일 구성

- Windows 학생에게는 `client/dist/학생화면전송.exe` **한 파일만** 전달하면 됩니다. Python 설치는 필요하지 않습니다.
- Android 학생에게는 `android/dist/학생화면전송.apk` **한 파일만** 전달합니다. `android/signing/`과 `android/keystore.properties`는 앱 업데이트용 서명 자료이므로 학생에게 배포하지 않습니다.
- 교사 노트북에는 `server/` 폴더 전체를 복사합니다. `node.exe`, `node_modules/`, `public/`, `server.js`, `recording.js`, `lesson-title.js`, `history.js`, `capture-requests.js`, `wifi-info.js`는 실행에 필요하므로 함께 보관하세요.
- `captures/`는 화면 기록 저장 위치입니다. 폴더가 없어도 저장할 때 자동으로 생성됩니다.
- 학생 설치 페이지의 다운로드를 제공하려면 `server/`와 함께 `client/dist/` 및 `android/dist/`의 상대 위치도 유지하세요.
- `client/student.py`, `client/server_address.py`, `client/single_instance.py`, `client/requirements.txt`는 향후 오류 수정과 실행 파일 재빌드를 위한 소스입니다. 학생에게 배포할 필요는 없습니다.

## 유지보수용 재빌드

```powershell
python -m pip install -r client/requirements.txt
python -m pip install pyinstaller==6.22.2
client\윈도우앱빌드.bat   # 또는 client\build-exe.ps1 — 테스트 → EXE 빌드 → dist\version.json
```

출력 파일은 `client/dist/학생화면전송.exe`와 `client/dist/version.json`입니다. **새 버전을 낼 때는 `client/student.py`의 `APP_VERSION`(Windows)과 `android/app/build.gradle`의 `versionCode`·`versionName`(Android)을 올린 뒤 빌드하세요.** 두 빌드 스크립트(`client/build-exe.ps1`, `android/build-apk.ps1`)가 `dist/version.json`을 만들고, 교사 서버는 이 파일로 학생 앱의 새 버전 여부를 판단합니다. 재빌드할 때는 해당 실행 파일을 먼저 종료하세요(트레이 아이콘 우클릭 → 종료). 트레이 아이콘에는 `pystray`가 필요하며 `client/requirements.txt`에 들어 있습니다.
