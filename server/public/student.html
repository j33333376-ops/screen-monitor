내 기기로 수업에 참여하기

선생님과 같은 Wi-Fi에 연결한 뒤, 기기에 맞는 앱을 설치하세요.
윈도우와 안드로이드 모두 같은 수업 코드로 참여합니다.

앱에 입력할 서버 주소

안드로이드 태블릿

갤럭시탭 등 · Android 8.0 이상 · 1.5.0 · 입력 기억·새 버전 알림·메시지·손들기

안드로이드 앱 다운로드 (.apk)
  1. 다운로드한 APK 파일을 열어 설치하세요. 설치 출처 허용이 필요한 경우 학교에서 허용한 방법으로 설치하세요.
  2. 학생 화면 전송 앱을 열고 서버 주소의 빈칸에 네 번째 숫자를 입력하세요. 기본값은 192 · 168 · 1 · 빈칸 : 8080입니다. 선생님 주소가 다르면 나머지 칸도 바꿉니다. 수업 코드, 학년·반·번호·이름을 입력하세요.
  3. 전송 시작을 누르고 화면 공유 창에서 지금 시작을 선택하세요. 공유 범위 선택 창이 나오면 전체 화면을 선택하세요.
  4. 학습 앱으로 이동하세요. 도움이 필요하면 앱의 ✋ 선생님 호출을 누르세요. 앱이나 알림의 전송 중지로 언제든 멈출 수 있습니다.

윈도우 PC

노트북·데스크톱 · 1.5.0 · 입력 기억·새 버전 알림·메시지·손들기

윈도우 앱 다운로드 (.exe)
  1. 다운로드한 실행 파일을 여세요. 별도의 Python 설치는 필요하지 않습니다. 한 번 입력한 서버 주소·학년·반·번호·이름은 다음에 자동으로 채워지므로, 보통은 수업 코드만 넣으면 됩니다.
  2. 서버 주소의 빈칸에 네 번째 숫자를 입력하세요. 기본값은 192 · 168 · 1 · 빈칸 : 8080입니다. 선생님 주소가 다르면 나머지 칸도 바꿉니다. 수업 코드, 학년·반·번호·이름을 입력하세요.
  3. 전송 시작을 누르세요. 도움이 필요하면 ✋ 선생님 호출을 누르세요. 멈출 때는 전송 중지를 누릅니다.
  4. 창을 닫으면 프로그램이 끝나지 않고 작업 표시줄 오른쪽 끝 트레이 아이콘으로 숨으며 전송은 계속됩니다. 끝내려면 그 아이콘을 우클릭해 ‘종료’를 누르세요.

전송 중 선생님이 화면을 볼 수 있고 캡처를 PDF로 저장할 수 있습니다. 선생님 노트북에 더 새로운 앱이 있으면 앱에 ⬆ 새 버전 받기 버튼이 나타납니다. 선생님이 보낸 안내 문구는 앱 화면(안드로이드는 알림에도)에 표시되며, 문구 안의 인터넷 주소를 누르면 브라우저가 열립니다. 도움이 필요하면 ✋ 선생님 호출을 누를 수 있습니다. 화면 꺼짐·절전 후에는 자동 복구를 시도합니다. Android가 공유 권한을 종료하면 앱에서 ‘전송 재개’를 누르고 다시 허용하세요. 최근 앱 목록에서 앱을 지우면 공유를 중지합니다. 설치가 학교 관리 정책으로 차단되면 담당 선생님에게 알려 주세요. 이 배포본은 iPad를 지원하지 않습니다.
